# LangChain Learning Project

This is a learning project for LangChain.

## Project Structure

- Each learning topic is arranged in a different subfolder (e.g., `01_basics/`, `04_langgraph/`)
- `learnings.md` — general notes and takeaways across all topics
- `handoff.md` — records the current state of the project and how to continue, so both the user and Claude can pick up where we left off
- Other `*.md` files cover individual topics in depth

## Working Conventions

- When adding to `learnings.md`, always append to the end of the file — never insert mid-file
- Keep `handoff.md` up to date when wrapping up a session
